# My Family Tree

A family heritage platform for documenting ancestry, managing family relationships, preserving photographs and documents, and connecting generations.

**Status:** Phase 1 (solution architecture), awaiting approval. No application code yet.

Start with the architecture overview: [docs/architecture/00-overview.md](docs/architecture/00-overview.md)

## Planned stack

Laravel · React + TypeScript · Inertia.js · Tailwind CSS · PostgreSQL · Redis · D3.js · PWA · Nginx · S3-compatible storage · GitHub Actions

Installation, environment configuration and development commands will be added here in Phase 2 (see [docs/architecture/11-setup.md](docs/architecture/11-setup.md)).
