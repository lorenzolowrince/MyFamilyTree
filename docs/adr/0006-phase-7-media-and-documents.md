# ADR 0006: Phase 7 media and documents

Date: 2026-11-12 · Status: Proposed (awaiting review)

## What Phase 7 delivers

| Area          | Delivered                                                                                                                                                                                                                                       |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Storage       | Photos and documents live in private S3-compatible object storage (RustFS locally). Nothing is public; every request for a file is checked against the family's permissions.                                                                    |
| Safety        | Each upload is: identified by its content (not its name), stored in quarantine, scanned by ClamAV, re-encoded (images) or rendered (PDFs), and only then shown. A refused file is deleted and its uploader is told why, on screen and by email. |
| Privacy       | All metadata is removed from images, including GPS position. Only the date taken is kept, as the photo's date. Phone photos are turned upright before the orientation tag is removed. HEIC photos become JPEG.                                  |
| Photos        | Gallery with albums, filter by year and person, captions, dates, tagging people, profile pictures, and the family cover chosen from the gallery.                                                                                                |
| Documents     | PDF and scanned images, by kind (birth, marriage and death certificates, letters, land and religious records). Read on screen as page images; the file itself can be made view-only for Viewers and Contributors.                               |
| Timeline      | Photos and documents can be attached to timeline entries and are shown there to those who may see them.                                                                                                                                         |
| Allowance     | Each family's storage is counted and limited (10 GB by default). Settings show what is used. Deleted files are erased and their space returned after 30 days.                                                                                   |
| Notifications | Email when your upload is refused, and when you are tagged in a photo.                                                                                                                                                                          |

## Differences from the architecture documents

| Planned                                                            | Implemented                                                                                                                                                  | Reason                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Files served through 5-minute signed storage links                 | Files are **sent by the application** after a permission check on every request                                                                              | Works the same in Docker, tests and production, keeps storage unreachable from the internet, and lets the offline mode of Phase 9 cache photos from the application's own address. Signed links can replace this later without changing stored data if file traffic becomes a load problem. |
| Documents served from a separate download domain                   | The PDF is only ever sent as a **download** (never opened in the page), with a policy that forbids it to run anything; on screen people read **page images** | Gives the same protection without a second domain, which needs DNS and a certificate. A separate domain can be added when the production server is set up (Phase 10).                                                                                                                       |
| Original image kept                                                | Only the **re-encoded JPEG** is kept (longest edge at most 4096 pixels, quality 88)                                                                          | Keeping the original would keep its hidden data and location. The trade-off: transparent PNGs get a white background, and very large scans are reduced.                                                                                                                                     |
| TIFF for documents                                                 | Accepted; stored as JPEG, **first page only**                                                                                                                | Browsers cannot show TIFF. Multi-page scans should be uploaded as PDF.                                                                                                                                                                                                                      |
| PDF preview                                                        | The first **10 pages** are shown as images                                                                                                                   | Enough for certificates and letters; longer documents are read by downloading. Configurable.                                                                                                                                                                                                |
| Contributor uploads: "admins can switch to approval"               | Uploads by Contributors **always go live after the scan**                                                                                                    | The approval switch for media is not built yet. `change_requests` already allows photo and document proposals.                                                                                                                                                                              |
| `storage_key` example `families/{family}/photos/{id}/original.jpg` | As planned, plus `quarantine` in the same folder until the checks pass                                                                                       | One folder per file makes erasing complete.                                                                                                                                                                                                                                                 |
| Extra column                                                       | `rejection_reason` on photos and documents                                                                                                                   | So the uploader can be shown why a file was refused.                                                                                                                                                                                                                                        |

## Other decisions

- **A file is never released unscanned.** If ClamAV cannot be reached the file stays in quarantine and the job retries for about an hour, then the file is refused. Scanning can only be switched off by configuration (`CLAMAV_ENABLED=false`), which the automated tests do; one test talks to the real scanner when it is running.
- **The scanner is reached over the network** (clamd's INSTREAM command), so it needs no access to the application's files.
- **PDFs are read by Ghostscript in its locked-down mode** (`-dSAFER`), with time limits. A PDF that cannot be opened (damaged or password-protected) is refused.
- **Images larger than 100 megapixels are refused** before they are decoded.
- **Identical files are stored once per family** (compared by SHA-256 of the upload).
- **Visibility works as for people:** `family`, `restricted` (Editors and above) or `private` (Owner and Administrators). Nobody can set a level they could not see themselves. A file in quarantine or refused is visible only to its uploader.
- **The uploader may always edit and delete their own file** while they can still upload. Editors and above edit any file; only the Owner and Administrators delete any file.
- **Tagging respects privacy:** someone who may not see a person can neither tag them nor remove their tag.
- **A profile picture must be a photo the person is tagged in**, and is only shown to viewers who may see that photo. The family cover must be a photo the whole family can see.
- **Downloads are written to the audit log.** So are uploads, edits, deletions, refusals and scanner findings.
- **Space is reserved before a file is stored**, in one database statement, so two uploads cannot both take the last free space. The counter is corrected to the stored size once the file is processed.
- **Deleting is reversible for 30 days** (soft delete; `media:purge` runs nightly). The settings page shows how much space removed files still hold.

## Operating notes

- ClamAV needs about 1.5 to 2 GB of memory and downloads its virus definitions on first start (a few minutes). Until it is ready, uploads wait in quarantine.
- After changing code that queued jobs use, restart Horizon (`php artisan horizon:terminate`).
